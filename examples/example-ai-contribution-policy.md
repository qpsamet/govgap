# Example Open-Source Project: AI-Assisted Contribution Policy

*This is a synthetic example document included so the agent can be run
immediately on a clean clone. It is not a real project's policy.*

## Using AI assistance

You may use AI coding assistants to help prepare contributions to this project,
provided you follow the rules below.

## Review

All AI-generated code must be reviewed by a human maintainer before it is
merged. AI output is a suggestion, never a final contribution, and the decision
to accept a contribution always rests with a human reviewer.

## Disclosure and provenance

When a significant part of a contribution was produced with an AI tool, you must
disclose this. Add an `Assisted-by: <tool name>` trailer to your commit message.
You remain fully responsible for everything you submit, including any AI-assisted
parts.

## Security

You must run the project's security scanner on any AI-generated code and resolve
any flagged vulnerabilities before opening a pull request. Do not submit code
that introduces known-insecure patterns.

## Style

Contributions should follow the existing project style guide.
